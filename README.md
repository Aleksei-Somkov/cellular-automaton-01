A simple website that displays 4 strips of cellular automaton (each with the radius of 2 neighbors).
Use this link to open it [ https://aleksei-somkov.github.io/cellular-automaton-01/ ]

<img width="1920" height="1080" alt="download (4)" src="https://github.com/user-attachments/assets/d3f64c57-0093-4555-adef-a62515af6724" />

To see new patterns, you can simply refresh the page.

If you are experiencing issues with visibility on mobile, try turning on the "desktop site" option in the settings, as well as zooming out.
